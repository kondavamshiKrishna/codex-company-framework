# Domain Company Example

This is a sanitized example of how a domain-specific company can be structured.

It intentionally does not include private project reports, database data, user
paths, secrets, or trading records.

Example company skill:

```text
domain-project-company
```

Example worker roles:

- product manager
- backend engineer
- frontend engineer
- QA/test engineer
- data engineer
- documentation writer
- independent validation agent
