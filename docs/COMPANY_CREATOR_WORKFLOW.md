# Company Creator Workflow

1. Inspect the project folder.
2. Identify project type, runtime, data stores, and risks.
3. Propose company name and company skill.
4. Propose worker roles.
5. Define memory layout.
6. Define report layout.
7. Define runtime and DB routing rules.
8. Define permissions for each worker.
9. Create company skill and worker templates.
10. Create smoke test.
11. Ask Owner to review before production use.
