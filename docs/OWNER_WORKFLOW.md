# Owner Workflow

1. Identify project/company context.
2. Read current company memory.
3. Inspect real files/runtime before claims.
4. Decide whether workers are needed.
5. Spawn or instruct workers with exact scope.
6. Review worker output as draft.
7. Verify important claims independently.
8. Accept, reject, or refine.
9. Decide next task.
10. Update memory when useful and allowed.

Owner review format:

```text
Verdict:
Accepted:
Rejected / unsupported:
Evidence checked:
Remaining gaps:
Next task:
```
