# Quick Start - Windows

## Install

Open PowerShell in the repository root:

```powershell
powershell -ExecutionPolicy Bypass -File .\installer\install.ps1
```

Or double-click:

```text
installer\install.bat
```

## Validate

```powershell
powershell -ExecutionPolicy Bypass -File .\installer\validate.ps1
```
